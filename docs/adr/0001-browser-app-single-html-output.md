# ADR 0001: ブラウザ単体アプリで組み立て、単一 HTML を出力する

## 文脈

Markdown と SVG からマニュアルを作りたい。実現方法として次の案があった。

1. **ブラウザ単体アプリ**: ファイルをブラウザに取り込み、その場で組み立てて HTML をダウンロードする
2. **CLI 生成ツール（Node）**: 素材フォルダを指定してコマンドで HTML を生成する（静的サイトジェネレータ型）
3. **サーバー付き Web アプリ**: 素材をサーバーに保存し、ブラウザで編集・配布する

## 決定

**案 1（ブラウザ単体アプリ）** を第 1 段階とする。出力は **CSS・SVG を内包した単一 HTML** とする。

- 配布先はファイル共有やメールで受け取るため、外部参照のない 1 ファイルが最も扱いやすい
- 利用者は 1 名〜少人数で、インストール不要・サーバー不要が望ましい
- 素材（Markdown / SVG）は手元のエディタと作図ツールで作る前提とし、アプリは「組み立て」に専念する

組み立てロジックは `src/core/` に **DOM API 以外に依存しない純粋なモジュール** として分離し、
将来 案 2（CLI）を追加するときに jsdom 経由で再利用できるようにする。

## 結果

- 利点: 導入が容易、データが外部に出ない、配布物が 1 ファイル
- 欠点: 章の内容をアプリ内で編集できない（取り込み直しが必要）、作業状態の保存はブラウザ依存
- 技術: Vite + TypeScript、marked（Markdown）、DOMPurify（サニタイズ）、Vitest + jsdom（テスト）
