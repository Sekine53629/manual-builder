# はじめに

## 目的

このマニュアルは、Manual Builder の動作確認用サンプルです。
Markdown ファイルを章として、SVG ファイルを図として取り込む流れを示します。

## 対象読者

- 業務マニュアルを Markdown で書きたい担当者
- 図を SVG（draw.io、Inkscape、Excalidraw など）で作成している担当者

> **注意**: 取り込んだファイルはブラウザ内だけで処理され、サーバーには送信されません。

## 使い方の流れ

| 手順 | 操作 | 結果 |
|---|---|---|
| 1 | `.md` ファイルを取り込む | 章として追加される |
| 2 | `.svg` ファイルを取り込む | 図として登録される |
| 3 | 「HTML を書き出す」を押す | 単一の HTML ファイルがダウンロードされる |
