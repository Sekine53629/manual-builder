マニュアル情報

章

    章をクリックすると編集できます。「＋」でその章の直後に挿入、グループに同じ名前を入れた連続する章が 1 つの章（第N章）にまとまります。

    素材

    .md / .json / .svg / .png / .txt をここにドロップ
    プロジェクトフォルダの chapters / images / catalog に保存されます

    Markdown では ![説明](ファイル名.svg) / ![説明](ファイル名.png)、操作経路は [[chips:m_tabs:F10, m_option1:F1]] で参照します。

    メッセージ

      プロジェクトの保存フォルダを開いてください

      マニュアルは「保存フォルダ」の中にプロジェクトごとのフォルダ（manual.json + chapters/ + images/ + catalog/ + output/）として保存されます。 このリポジトリの projects/ フォルダを選ぶと、サンプル（sample）が開けます。

      このブラウザはフォルダへの保存（File System Access API）に対応していません。Chrome または Edge で開いてください。
