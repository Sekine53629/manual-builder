## 1. 背景と目的

業務マニュアルを **Markdown で書き、SVG の図を添えて、HTML 形式で配布**したい。
Word やスライドで作るマニュアルは図の差し替えや版管理が煩雑なため、テキスト（Markdown）と
図（SVG）を素材として管理し、配布物（HTML）を機械的に組み立てる。

第 1 の到達目標は、既に配布している PDF 版マニュアル（`input/reference/pdf/` の統合版・単体版）と
**同じ見た目・同じ構成の HTML** を、同じ素材から生成できることである（0.2 で達成。既知の差は 6 章）。

第 2 の目標は、素材をマニュアル（プロジェクト）ごとのフォルダに保存し、**原稿を見ながら出力を確認して
編集できるエディタ**にすることである（0.3）。

## 2. スコープ

### 2.1 対象

- **保存フォルダとプロジェクト**: 利用者が選んだ保存フォルダの中に、1 マニュアル = 1 フォルダ
  （`manual.json` + `chapters/` + `images/` + `catalog/` + `output/`）。ブラウザから直接読み書きする（Chrome / Edge）
- 素材の種類
  - Markdown（`.md`）: 原稿。front matter（title / subtitle）、`[[chips:...]]`、生 HTML（フロー図・出典行）を含む
  - 手順 JSON（`.json`、`title` + `steps[]`）: 操作マニュアルの手順データ
  - メニュー定義 JSON（`catalog/menus.json`、`menus[]` + `screens[]`）: チップの解決と「メニュー構成とアイコン一覧」章の生成
  - 画像（`.png` 等）・図（`.svg`）: data URI / インライン SVG で埋め込む
  - ツリー表示（`catalog/menu-tree.txt`）
- **3 ペインエディタ**: ソース（Markdown / JSON）・生成 HTML（読み取り専用）・プレビュー。スクロール同期、自動保存
- 章の挿入・並べ替え・一覧からの除外、グループ（第N章）の自動採番、表示タイトルの上書き
- 単体出力（章内目次付き）と統合版出力（表紙・全体目次・章バッジ）
- 印刷（PDF 保存）、`output/` への **外部参照のない単一 HTML** の書き出し
- CLI（Node）: `manual.json` から同じ組み立てを行う

### 2.2 対象外（現時点）

- サーバー・ログイン・共同編集
- Chrome / Edge 以外のブラウザ（File System Access API 非対応）
- Word / PDF への直接書き出し（ブラウザの印刷機能で代替）
- 目次へのページ番号表示、ページフッター（HTML では確定できない。PDF 化時にブラウザのヘッダー／フッター機能で補う）
- 画像のトリミングなどの画像編集

## 3. 利用者と利用環境

- 利用者: マニュアル作成担当者（1 名〜少人数）。読み手は配布先の職員
- 環境: Windows 11 + Chrome/Edge。ファイルは PC 上の保存フォルダとブラウザ内だけで処理し、外部送信しない
- 取り込む Markdown は BOM 付き UTF-8 のことがある（日本語 Windows の既定）

## 5. 非機能要件

- セキュリティ: 取り込んだ Markdown / SVG / JSON 由来の HTML はすべて DOMPurify を通してから埋め込む。
  生 HTML は `div` + `class` の範囲で通す
- 可搬性: 出力 HTML は外部ファイル・外部 URL を参照しない（CSS・SVG・画像をすべて内包）
- 再現性: 同じフォルダからは CLI とブラウザで同じ HTML が生成される（同じ `src/core/` を使う）
- 機密: 利用者のプロジェクト（`projects/` の `sample/` 以外）は Git 管理外。配布した HTML は Tier 1 の規約どおり
  `archive/dist/` に日付付きで保存する（個人情報を含むものは `_private/`）
- 検証: 単体テスト（core・同期ロジック）に加え、ヘッドレス Chrome でアプリを操作するスモークテストを持つ

## 6. 参考 PDF との既知の差

| # | 事項 | 状況 |
|---|---|---|
| D-1 | 全体目次のページ番号、各ページ下部のフッター | HTML では確定できない。PDF 化時にブラウザの「ヘッダーとフッター」で代替 |
| D-2 | 手順ページの画面写真 | 素材から切り出し画像が除かれているため未収録。`steps[].images` にファイル名を書けば差し込める |
| D-3 | 「調剤内規」の章 | 原稿（Markdown）が素材に無いため統合版に含まれない（20 本／参考 PDF は 21 本） |
| D-4 | グリッドに F1〜F12 以外のキー（SHIFT+F12 など） | 参考 PDF と同じく一覧には出さない（チップ参照は可能） |
